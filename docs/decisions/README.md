# Architecture Decisions

Use this directory for short Architecture Decision Records. Security-sensitive decisions should be
kept in the repository so humans and AI review tools can evaluate code against the intended design.

## Template

```markdown
# ADR-0000: Title

## Status

Accepted

## Context

What problem, threat, or constraint forced this decision?

## Decision

What did we decide?

## Consequences

What becomes easier, harder, or riskier because of this decision?

## Alternatives Considered

What did we reject, and why?
```
